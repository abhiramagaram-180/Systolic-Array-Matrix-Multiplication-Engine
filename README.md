# 4x4 Systolic Array Matrix Multiplier

This project is a Verilog-2001 design of a 4x4 systolic array that multiplies two 4x4 matrices of 8-bit unsigned numbers (C = A x B). It is output-stationary: each of the 16 processing elements (PEs) keeps one element of C in its own 20-bit accumulator, while A values flow to the right and B values flow down. The Verilog design is the **verified reference model**: a self-checking testbench compares it against a software reference for several hardcoded and random cases. The same design is then redrawn by hand in **Logisim**, and its results are checked against the same expected values.

## Folder layout

```
rtl/        design files (pe.v, systolic_array.v, control.v, top.v)
tb/         testbench (tb_top.v)
scripts/    Verilog simulator commands (run.sh)
logisim/    ROM image generator (make_rom.py), generated ROM images, test cases
docs/       spec, explanations, hand trace, Logisim build guide, viva notes, report draft
README.md   this file
```

## How to run the Verilog reference model

```bash
bash scripts/run.sh      # compile + simulate, prints PASS/FAIL per test
gtkwave dump.vcd         # view the waveform
```

`run.sh` exits with a non-zero status if any test prints FAIL.

## Files

| File | Job |
|------|-----|
| `rtl/pe.v` | One processing element: multiplies two 8-bit inputs, adds to a 20-bit accumulator, and passes the inputs on to the right and downward. |
| `rtl/systolic_array.v` | Builds the 4x4 grid of PEs and wires them together. |
| `rtl/control.v` | FSM (IDLE/RUN/DONE) and cycle counter that feeds the correct A and B values to the array each cycle and raises `done`. |
| `rtl/top.v` | Connects the controller to the array; this is the design's top module. |
| `tb/tb_top.v` | Testbench with hardcoded and random matrices, checked against a software reference. |
| `scripts/run.sh` | Compiles and runs the simulation and reports failure through its exit code. |
| `docs/spec.md` | The design specification. |
| `docs/control_explained.md` | Beginner explanation of `control.v`. |
| `docs/pe_and_array_explained.md` | Beginner explanation of `pe.v`, `systolic_array.v` and `top.v`. |
| `logisim/make_rom.py` | Writes the unskewed ROM image files for each test case and prints the expected C and the skewed feed table. |
| `logisim/roms/<case>/` | Generated ROM images (`A_row0.hex` ... `B_col3.hex`) to load into the Logisim ROMs. |
| `logisim/test_cases.md` | Table of every case with A, B and expected C (generated by `make_rom.py all`). |
| `docs/logisim_build_guide.md` | Step-by-step guide to building the circuit in Logisim. |
| `docs/handtrace_2x2.md` | Worked 2x2 example, cycle by cycle. |
| `docs/viva_notes.md` | 33 likely viva questions with short answers (25 general, 8 on Logisim). |
| `docs/report_draft.md` | Draft of the project report. |

## Parameters

| Parameter | Value |
|-----------|-------|
| Array size N | 4 x 4 |
| Inputs | 8-bit unsigned |
| Accumulators | 20-bit |
| Latency | 10 cycles = 3N - 2 (t = 0..9); `done` goes high the cycle after t = 9 |

## Logisim version of the design

The circuit is drawn by hand in Logisim following `docs/logisim_build_guide.md` (no `.circ` file is generated by the scripts).

```bash
python logisim/make_rom.py 4 hand_picked   # one case: writes logisim/roms/hand_picked/*.hex
python logisim/make_rom.py all             # every case, and rewrites logisim/test_cases.md
```

The script prints the expected C (decimal and hex) and the cycle-by-cycle table of what enters each row and column after the skew. Load the images into the ROMs (right-click a ROM, Load Image), run the circuit and compare the 16 probes with the expected C.

### Verilog module to Logisim part

| Verilog | Logisim part |
|---------|--------------|
| `pe.v` | `PE` subcircuit: 2 Bit Extenders (8 to 20 bits), 20-bit Multiplier, 20-bit Adder, 20-bit `acc` Register, two 8-bit Registers for `a_out` and `b_out` |
| `systolic_array.v` | 4x4 grid of `PE` subcircuits in `main`; `a_link` and `b_link` are plain wires between neighbours |
| `control.v` state and counter | `run` Register, 4-bit Counter `t`, Comparator `t = 10` (this is `done`), and 5 gates |
| `control.v` feeder (`A[i][t-i]`, `B[t-j][j]`) | 8 ROMs addressed by `t` (unskewed data) plus i delay Registers on row i and j on column j |
| `A_flat`, `B_flat` | ROM contents (loaded from `logisim/roms/<case>/`) |
| `clear` | `Start AND NOT run`, wired to the Clear pin of every Register and the Counter |
| `done` | Comparator output (`t` equals 10) |
| `top.v` | The `main` circuit |
| `tb_top.v` | You, with `make_rom.py` and `test_cases.md`: load a case, press Start, tick, compare probes |
